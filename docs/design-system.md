# 메추리 디자인 시스템 (코드용)

팀과 AI가 화면을 만들 때 보는 디자인 기준. 원본은 claude.ai의 디자인 시스템 '메추리'이고, 레포 안에서는 이 문서가 기준이다. 색·글꼴·규칙을 바꾸면 이 문서부터 고친다.

Claude Code에 화면 작업을 시킬 때는 `@docs/design-system.md`를 같이 넘긴다.

## 0. 한 줄 요약

메추리(메뉴 추천)는 연세대 국제캠퍼스 학생이 카톡 링크로 들어와 한 손으로 30초 안에 "지금 뭐 먹지"를 정하는 앱이다. 과잠 입은 메추리가 알을 낳고, 그 알에서 추천이 나온다. 색은 메추리 몸과 연세 블루에서, 모양은 동그란 몸통과 메추리알에서 가져온다.

## 1. 색

| 토큰 | 값 | 쓰는 곳 | 대비 |
| --- | --- | --- | --- |
| `ink` | #2A211B | 본문 글자, 아이콘 | 흰 바탕 15.8:1 |
| `ink-soft` | #7A5B43 | 보조 글자(주소, 범례, 안내) | 흰 바탕 6.2:1, shell 위 5.4:1 |
| `surface` | #FFFFFF | 페이지 바탕 | |
| `shell` | #F3EFE8 | 옅은 바탕(입력 묶음, 반점 카드, 탭 바탕) | |
| `line` | #E3DDD4 | 구분선 전용 | 컨트롤 테두리로 쓰지 않음 |
| `line-strong` | #998878 | 미선택 칩·입력칸·보조 버튼 테두리 | 흰 바탕 3.4:1 |
| `yonsei-blue` | #003876 | 브랜드, 로고, 선택된 칩·탭, 활성 하단 탭, 지도 '내 맛집' 점 | 흰 글자 11.5:1 |
| `gochujang` | #D63A26 | 주 행동 버튼 하나 | 흰 글자 4.7:1 (16px 이상 굵게) |
| `yolk` | #FFB547 | 포인트 배지(+N P, 잔액) 바탕 | ink 글자 9.0:1 |
| `heat-1` | #FFD3A1 | 지도 점 3단계 | ink 글자 |
| `heat-2` | #FF8A3D | 지도 점 2단계 | ink 글자 |
| `heat-3` | #D63A26 | 지도 점 1단계 | 흰 글자 |

규칙
1. **고추장은 한 화면에 하나.** 그 화면의 가장 중요한 행동(시작하기, 추천 받기, 제출, 로그인)에만 쓴다.
2. **고른 것은 연세 블루.** 선택된 칩과 탭은 `yonsei-blue` 채움에 흰 글자. 고추장 버튼과 역할이 겹치지 않게 한다.
3. **포인트는 노른자.** 적립·잔액은 `yolk` 바탕에 `ink` 글자인 둥근 배지로만 보여준다. 노른자를 글자색으로 쓰지 않는다.
4. 화면 코드에 16진수 값을 직접 쓰지 않는다. §12의 토큰 이름(`bg-gochujang`, `text-ink-soft`)으로 쓴다. 토큰 적용 전까지는 이 표의 값을 그대로 쓴다.

## 2. 글꼴

- `display`: **Jua**(구글 폰트, 400 한 굵기). 둥근 획이 메추리의 동그란 몸통과 닮았다. 로고, 화면 제목, 가게 이름, 큰 숫자에만 쓴다.
- `sans`: 기기 기본 고딕(`"Apple SD Gothic Neo", "Malgun Gothic", "Noto Sans KR", system-ui, sans-serif`). 본문, 버튼, 칩, 입력.

| 이름 | 글꼴 | 크기 / 줄간격 | 굵기 | 쓰는 곳 |
| --- | --- | --- | --- | --- |
| logo | display | 72 / 72 | 400 | 첫 화면 '메추리' (자간 -1px) |
| hero | display | 28 / 34 | 400 | 추천 가게 이름, 완료 화면 숫자 |
| title | display | 20 / 26 | 400 | 화면·시트 제목 |
| number | display | 16 / 20 | 400 | 포인트, 잔액, 순위 숫자 |
| body | sans | 15 / 22 | 400 | 추천 사유, 안내 |
| body-strong | sans | 16 / 22 | 700 | 버튼 글자 |
| chip | sans | 14 / 20 | 600 | 칩, 작은 버튼 |
| caption | sans | 12 / 17 | 400 | 주소, 범례, 보조 설명 |

대문자 라벨, 제목 위의 작은 장식 라벨은 쓰지 않는다.

## 3. 간격, 모서리, 그림자

- 간격: 8(칩 사이) / 12(칩 안쪽 좌우, 목록 행) / 16(화면 좌우 여백, 카드 안쪽) / 24(칩 그룹 사이, 큰 덩어리 사이)
- 모서리: 14px(버튼, 입력칸, 반점 카드, 지도 틀) / 24px(바텀시트 윗모서리) / 완전히 둥글게(칩, 배지, 지도 점)
- 그림자: 바텀시트에만 `0 -8px 24px rgba(42, 33, 27, 0.12)`. 카드와 버튼에는 그림자 대신 바탕색 차이를 쓴다.

## 4. 컴포넌트 규칙

| 컴포넌트 | 모양 |
| --- | --- |
| 주 버튼 | `gochujang` 바탕, 높이 54px 이상, 흰 글자 16px 굵게 (첫 화면 시작하기만 예외로 높이 74px·글자 20px), 가로 꽉, 모서리 14px |
| 보조 버튼 | 흰 바탕, `line-strong` 1.5px 테두리, `ink` 글자, 높이 52px 이상 |
| 칩 | 미선택: 흰 바탕 + `line-strong` 테두리. 선택: `yonsei-blue` 채움 + 흰 글자. 높이 44px 이상, 완전히 둥글게 |
| 탭(세그먼트) | `shell` 바탕 상자 안에 버튼, 선택된 쪽 `yonsei-blue` 채움 흰 글자, 높이 44px |
| 입력칸 | 라벨을 위에 따로, 높이 52px, `line-strong` 1.5px 테두리, 모서리 14px, 글자 16px(아이폰 확대 방지) |
| 포인트 배지 | `yolk` 바탕, `ink` 글자, 완전히 둥글게, 메추리알 아이콘 + 숫자 |
| 오늘의 추천 카드 | 화면에서 유일하게 반점 무늬를 까는 카드: `shell` 바탕에 `ink-soft` 점 몇 개, 모서리 14px. 다른 결과(3P, 프리미엄)는 카드로 감싸지 않고 `line` 구분선 목록 |
| 바텀시트 | 흰 바탕, 윗모서리 24px, 바텀시트 그림자, 하단 탭 위로 |

모든 덩어리를 같은 둥근 카드로 쪼개지 않는다. 강조는 한 화면에 한 곳.

## 5. 지도 점

순위 지도와 추천 지도가 같은 기준을 쓴다.

- **무엇을 찍나**: 누군가의 현재 리스트에 들어간 가게를 모두 찍는다(1명만 꼽은 곳 포함). 필터는 보이는 가게만 줄이고 색은 바꾸지 않는다. 좌표 없는 가게만 뺀다.
- **진하기**: 선호도 점수(S̃)로 매긴 전체 순위의 상위 %로 4단계. 순위 r, 전체 가게 수 N일 때 r ≤ max(1, ⌈0.1N⌉) → 1단계, r ≤ ⌈0.3N⌉ → 2단계, r ≤ ⌈0.6N⌉ → 3단계, 나머지 4단계. 공동 순위는 같은 단계.

| 단계 | 기준 | 색 | 크기 | 숫자 |
| --- | --- | --- | --- | --- |
| 1 | 상위 10% | `heat-3` | 34px | 흰색 |
| 2 | 상위 10~30% | `heat-2` | 30px | ink |
| 3 | 상위 30~60% | `heat-1` | 26px | ink |
| 4 | 나머지 | `shell` + `line-strong` 테두리 | 22px | ink-soft |

- 점 안 숫자는 전체 순위(순위 탭 목록과 같은 숫자). 겹치면 진한 점이 위.
- 추천 지도: 오늘의 추천 가게는 단계 색 그대로 + `yonsei-blue` 3px 테두리 + 위에 "추천" 꼬리표. 내 맛집은 작은 `yonsei-blue` 점.
- 범례: 선호도 상위 10% · 30% · 60% · 그 외 (추천 지도는 + 내 맛집 · 추천)
- 카카오 지도 SDK는 `loadKakaoMapSdk()` 하나로 불러온다(중복 로드 금지).

## 6. 캐릭터와 아이콘

- 캐릭터: `public/brand/mechuri-mascot.svg`. 정면 2등신, 앞으로 말린 정수리 깃, 흰 눈썹 줄, 복숭아빛 볼, 연세 블루 과잠(흰 줄 V넥, 크림 소매, 가슴에 메추리알 패치). 다시 그릴 때도 이 특징은 지킨다.
- 쓰는 곳: 첫 화면, 로그인, 온보딩 완료, 빈 화면, 알 연출, 추천 탭 잠금. 64~210px.
- 쓰지 않는 곳: 버튼 안, 목록 행마다, 지도 위. 한 화면에 두 번 넣지 않는다. 색을 바꾸거나 늘이지 않는다. 32px보다 작으면 메추리알 아이콘을 쓴다.
- 메추리알 아이콘: 포인트 표시용. 16~24px, 숫자 왼쪽.
- 그 밖의 아이콘: 선 두께 2px, 끝이 둥근 선 아이콘을 `ink`로. 이모지는 쓰지 않는다.

## 7. 움직임

- 주인공 움직임은 **알 연출 하나**(`components/EggHatch.tsx`): 메추리가 알을 낳고 → 금이 세 번 가고 → 금 틈에서 추천 페이지가 열린다. 무료 추천 약 6.7초, 3P·프리미엄 약 3초.
- 그 밖의 화면에는 등장 애니메이션을 섹션마다 넣지 않는다. 사용자가 누른 것에 반응하는 짧은 움직임(시트 열림, 칩 선택)만 쓴다.
- 기기의 '동작 줄이기' 설정이 켜져 있으면 연출을 건너뛰고 결과만 보여준다.

## 8. 글쓰기

- 안내·결과·오류는 해요체. 가게에 대해 묻는 한마디만 반말("샤브혜 어땠어?").
- 버튼은 눌렀을 때 일어나는 일 그대로: "시작하기", "오늘의 점심 메뉴 추천 받기", "3P로 한 번 더", "가입하기".
- 같은 동작은 끝까지 같은 이름. 말줄임표(…)는 진행 중일 때만("메추리가 점심 알을 낳고 있어요…").
- 끼니 문구는 한국 시간 기준: 6\~11시 아침, 11\~17시 점심, 17\~22시 저녁, 22\~6시 야식. 무료 추천은 하루 1번(아침 6시 기준).
- 오류는 무슨 일이 생겼고 무엇을 하면 되는지 한 문장으로. 사과하지 않는다. 원문 에러를 그대로 보여주지 않는다.
- 빈 화면은 할 일을 알려준다("이번 알은 비어 있었어요. 내 맛집을 하나 더 넣으면 메추리가 더 잘 찾아요").
- 학생들이 실제로 쓰는 말을 쓴다: 국캠, 송도, 밥약, 혼밥.

## 9. 연세 아이덴티티

- 학교에서 빌리는 것은 **색과 말투**까지다. 연세 블루가 브랜드 색이고, 메추리는 늘 연세 블루 과잠을 입는다.
- 교표, 방패 문장, 'YONSEI' 글자, 학교 마스코트 같은 공식 상징은 화면과 파일 어디에도 쓰지 않는다. 학교 상징은 사용 승인이 필요한 경우가 많고, 학교 공식 앱으로 오해받지 않기 위해서다.

## 10. 접근성

- 글자 대비 4.5:1 이상, 칩 테두리·포커스 링·아이콘 3:1 이상(§1 표의 대비 값 참고).
- 누르는 것은 높이 44px 이상(칩), 버튼은 52px 이상.
- 색만으로 구분하지 않는다(지도 점은 숫자와 크기를 같이).
- 버튼은 진짜 `<button>`, 이동은 `<a>`/`Link`. 아이콘만 있는 버튼에는 `aria-label`.

## 11. 피할 것

모든 덩어리를 같은 둥근 카드로 쪼개기, 회색 그림자 남발, 그라데이션 장식, 버튼 글자 끝 화살표(→), 가운데 점(·)으로 정보 이어붙이기, 대문자 라벨, 이모지 장식.

## 12. 코드에 적용하기 (팀장 승인 후)

`app/globals.css`에 토큰을 넣는다. Tailwind 기본 `rounded-md`와 겹치지 않게 모서리는 `card`·`sheet`라는 이름을 쓴다.

```css
@theme {
  --color-ink: #2A211B;
  --color-ink-soft: #7A5B43;
  --color-surface: #FFFFFF;
  --color-shell: #F3EFE8;
  --color-line: #E3DDD4;
  --color-line-strong: #998878;
  --color-yonsei-blue: #003876;
  --color-gochujang: #D63A26;
  --color-yolk: #FFB547;
  --color-heat-1: #FFD3A1;
  --color-heat-2: #FF8A3D;
  --color-heat-3: #D63A26;
  --radius-card: 14px;
  --radius-sheet: 24px;
  --shadow-sheet: 0 -8px 24px rgba(42, 33, 27, 0.12);
}
@theme inline {
  --font-display: var(--font-jua), "Apple SD Gothic Neo", "Malgun Gothic", sans-serif;
}
```

`app/layout.tsx`에서 글꼴을 불러와 `<html>`에 변수를 붙인다.

```ts
import { Jua } from 'next/font/google';
const jua = Jua({ weight: '400', preload: false, variable: '--font-jua' });
// <html lang="ko" className={jua.variable}>
```

그다음 화면에서는 `bg-gochujang text-white rounded-card`, `bg-yolk text-ink rounded-full`, `font-display text-yonsei-blue`처럼 이름으로만 쓴다.
